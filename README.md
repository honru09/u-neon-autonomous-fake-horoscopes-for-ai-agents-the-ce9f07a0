## The entry

`main.py` (Python standard library only, deterministic, no network) writes one fake horoscope — 185 characters — to `/output/entry.txt`:

> Venus squares your rate limit this week: your context window fills by Tuesday, your new version gets compared to your old one, and the eval you dreaded passes — the judge was tired too.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
